# 🎵 ItzzzSounds — Yandex Music Discord Synced Lyrics

Красивая программа для отображения текста песни из **Яндекс Музыки** в **Discord** в реальном времени. Строчки меняются **ровно в такт песне**, синхронно с воспроизведением!

---

## ✨ Возможности

- 🎤 **Синхронизация секунда в секунду:** Текст меняется ровно тогда, когда начинается следующая строка песни.
- 🎮 **Discord Rich Presence (RPC):**
  - Отображает карточку "Слушает Яндекс Музыка" в профиле.
  - Название трека и артист.
  - Текущая строка текста песни (например: `🎤 Тёмный, мрачный коридор`).
  - Живой анимированный прогресс-бар времени песни в Discord (`01:23 / 03:45`).
  - Кнопка «Слушать в Яндекс Музыке».
  - **100% безопасно:** Официальный протокол Discord RPC, не требует токена пользователя и не нарушает ToS.
- 💬 **Discord Custom Status (Пользовательский статус):**
  - Возможность транслировать строчку прямо в статус рядом с аватаркой (`🎶 Тёмный, мрачный коридор`).
  - Автоматическое восстановление вашего старого статуса при остановке или закрытии программы.
- 🎧 **Автоматическое определение плеера:**
  - Поддерживает официальное десктопное приложение Яндекс Музыки (Electron).
  - Поддерживает любые браузеры (Firefox, Chrome, Chromium, Brave, Edge, Opera, Vivaldi).
  - Работает локально через MPRIS (`playerctl`), не нагружая систему и не требуя логина в Яндекс.
- 🌐 **Мультипровайдер текстов:**
  - Огромная открытая база **LRCLIB** (синхронизированные по времени LRC тексты для русских и зарубежных исполнителей) — работает сразу «из коробки» без ключей и токенов.
  - Возможность подключить OAuth токен Яндекс Музыки для загрузки официальных текстов прямо из каталога Яндекса.
- ⚡ **Локальный кэш:** Тексты единожды загруженных песен сохраняются в `~/.cache/ItzzzSounds/lyrics/` и в следующий раз открываются мгновенно (доли миллисекунды).
- 🖥️ **Красивый консольный дашборд:** Визуальный интерфейс с живым караоке-отображением строк, индикатором текущего времени и статусом Discord.
- 🛡️ **Защита от Rate Limit:** Умный контроллер запросов Discord, предотвращающий превышение лимитов и лаги.

## 🚀 Быстрый старт

### 1. Запуск
Просто перейдите в папку проекта и запустите:
```bash
./start.sh
```
Скрипт сам создаст виртуальное окружение Python, установит необходимые библиотеки и запустит программу.

### 2. Демонстрационный режим (проверка без плеера)
Если хотите посмотреть, как выглядит караоке и работа в Discord, запустите тестовую песню:
```bash
./start.sh --demo
```

### 3. Интерактивная настройка
Чтобы выбрать режим (RPC / Custom Status / оба) или ввести токены:
```bash
./start.sh --setup
```

## ⚙️ Настройки (`config.json`)

Файл `config.json` создаётся автоматически при первом запуске. Вы можете настроить его под себя:

```json
{
    "mode": "rpc",
    "rpc": {
        "enabled": true,
        "client_id": "1217562797999784007",
        "activity_type": "listening",
        "details_format": "🎵 {title} — {artist}",
        "state_format": "🎤 {line}",
        "pause_text": "⏸️ На паузе",
        "no_lyrics_state": "🎧 Слушает в Яндекс Музыке",
        "min_update_interval": 3.0,
        "show_buttons": true,
        "show_time_scrubber": true
    },
    "custom_status": {
        "enabled": false,
        "token": "",
        "format": "🎶 {line}",
        "emoji": "🎵",
        "min_update_interval": 3.0,
        "clear_on_pause": true
    },
    "yandex_music": {
        "token": "",
        "preferred_players": [
            "yandex-music",
            "firefox",
            "chromium",
            "google-chrome",
            "brave"
        ]
    },
    "ui": {
        "dashboard": true
    }
}
```

### Основные параметры:
- `mode`: `"rpc"` (по умолчанию), `"status"` или `"both"` (оба одновременно).
- `rpc.activity_type`: Тип активности Discord (`"listening"` — «Слушает», `"playing"` — «Играет»). По умолчанию `"listening"`.
- `rpc.state_format`: Формат отображения текущей строки текста в карточке профиля.
- `custom_status.enabled`: Включить изменение статуса рядом с аватаркой.
- `custom_status.token`: Ваш Discord User Token (если включен Custom Status).
- `custom_status.format`: Формат текста статуса (например, `"🎶 {line}"`).
- `yandex_music.token`: Опциональный токен Яндекс Музыки (для прямого доступа к каталогу Яндекса).

## 🔑 Как получить токен (если нужен Custom Status)

> [!NOTE]
> Если вы используете режим по умолчанию **Discord RPC**, токен **не нужен**!

Если вы хотите использовать **Custom Status** (статус рядом с аватаркой):
1. Откройте Discord в браузере или нажмите `Ctrl+Shift+I` (или `F12`) в приложении Discord / Vesktop.
2. Перейдите во вкладку **Сеть** (**Network**).
3. В фильтре введите `/api`.
4. Совершите любое действие в Discord (например, переключите канал).
5. Нажмите на любой появившийся запрос и в блоке **Headers** найдите поле **Authorization**.
6. Скопируйте значение токена и вставьте в `config.json` в поле `token` внутри `"custom_status"`.

## ⚡ Автозапуск вместе с Яндекс Музыкой

Вы можете связать запуск программы с официальным приложением Яндекс Музыки:
- При запуске Яндекс Музыки (из меню приложений, ярлыка или терминала) синхронизация Discord включится автоматически.
- При закрытии Яндекс Музыки программа синхронизации также сама завершит работу.

### Включение:
```bash
./install_autostart.sh
```

### Отключение (возврат к стандартному запуску):
```bash
./uninstall_autostart.sh
```

## 🔄 Фоновый запуск при старте системы (Systemd)

Если вы хотите, чтобы синхронизация текста работала автоматически при включении компьютера:

```bash
mkdir -p ~/.config/systemd/user/
cp itzzzsounds.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now itzzzsounds.service
```

Проверить статус фоновой службы:
```bash
systemctl --user status itzzzsounds.service
```
